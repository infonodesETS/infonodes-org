# Letture

In questo folder le letture che MARLA apprezza, da cui impara e che vuole condividere.

Report e pubblicazioni di altre organizzazioni. Ogni PDF va accompagnato
da un file `.txt` con lo stesso nome, contenente:

```
Titolo: Titolo del report
Autori: Nome Cognome (opzionale)
Tipo: Report
Piattaforma: Nome dell'organizzazione che lo ha pubblicato
URL: https://link-alla-fonte-originale
Anno: 2026
Data: 2026-06-10        (o 10/06/2026 — usata per ordinare le letture)
Parole chiave: parola1, parola2, parola3
Descrizione: Breve descrizione del contenuto.
```

Il campo `URL` è obbligatorio: il box "Ultime cose che ho letto" in homepage
e le citazioni di MARLA rimandano sempre alla fonte originale.

Questi materiali NON appaiono nella sezione Pubblicazioni (riservata ai
lavori di info.nodes).
